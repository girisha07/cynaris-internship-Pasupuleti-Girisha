# W1D1: Python for ML — NumPy and CSV Fundamentals

## Overview

This project covers fundamental concepts of NumPy and Pandas as part of the Cynaris AI/ML internship.

## Topics Covered

### NumPy Fundamentals

* 1D, 2D, and 3D arrays
* Array shapes
* Broadcasting
* Vectorised operations
* Matrix multiplication
* Statistical operations
* Correlation analysis

### Pandas CSV Fundamentals

* Loading CSV datasets
* Exploring dataset structure
* Selecting rows and columns
* Statistical summaries
* Filtering records
* Handling missing values
